# Megashop
Built a basic e-commerce site with product listin🛒 MEGA MART — Cartoon Brutalist E-Commerce Store
MEGA MART is a lightweight, full-stack Single Page Application (SPA) e-commerce store built with a striking Cartoon Brutalist design aesthetic.
It provides a complete end-to-end shopping experience—from product browsing and real-time cart manipulation to authentication and order tracking.

✨ Key Features
🎨 Unique Cartoon Brutalist UI: Neo-brutalist borders, hard shadows, vibrant color palettes, and typography (Bungee & Public Sans).
📱 Client-Side SPA Routing: Fast, smooth, single-page navigation powered by the HTML5 History API (pushState / popstate).
🔒 User Authentication: Session-based user registration, login, state persistence, and logout capabilities.
🛍️ Product Exploration: Category filtering, real-time client-side search, inventory tracking, and dedicated product detail views.
🛒 Interactive Shopping Cart: Add items, adjust quantities dynamically, remove products, and compute totals in real time.
📦 Order Processing: One-click checkout mechanism with order history and itemized receipts.

🛠️ Tech Stack
Frontend
HTML5 / CSS3: Custom responsive styles, CSS grid/flexbox, custom properties (variables), brutalist design design system.
Vanilla JavaScript (ES6+): SPA router, state management, Async/Await API layer, dynamic DOM rendering.
Backend (Recommended Setup)
Runtime: Node.js
Framework: Express.js
Database: SQLite / PostgreSQL / MongoDB
Authentication: Express Session / JSON Web Tokens (JWT) & bcrypt for password hashing
